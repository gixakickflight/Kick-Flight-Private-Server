Release 2.11.800 Announcement

2026-11-05

Disc 3D model fixed in disc detail, with rotation in the enlarged view.

Fixed

  • The disc detail window now shows the disc's 3D summon model, both in the detail box and in the enlarged view.
  • In the enlarged view you can drag to rotate the model.

Changed

  • The client now loads its patches through a new internal native library, which makes future updates safer.
  • Admins can now tune the carry slowdown (per object type and role) from the server balance settings.

Update required

  • Android clients on 2.11.706 and older must update to keep playing.
  • It installs over 2.11.706 without uninstalling (same signature), so your data is kept.
