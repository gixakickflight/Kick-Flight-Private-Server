New matchmaking and more bot variety

2026-10-19

Better team composition in Scramble, Flag Flight, and Rapid Ball.

Team formation and bots

  • Matchmaking uses human player roles to guide team assignments, balances the number of human players on each team where possible, and keeps parties together.
  • When bots are needed, matchmaking fills open spots with complementary Kickers and varied Disc decks. Decks are selected to fit each bot's role, useful Disc effects, and that Kicker's cast times.
  • Bot builds include healing-focused options with Ruriha, traps with Owlbert, speed with Grenhawk, and damage support with Sid.
  • Combat AI behavior is unchanged.

Patch 2.11.3

2026-10-11

Stability update. Please download the new APK from the website.

Gameplay

  • Rush pursuit discs now push the target along instead of making it orbit around you.
  • Tutorial mode loads again.

Fixes

  • Opening a disc's skill description no longer breaks the summon preview.
  • The title screen loads only once at startup.
  • Pressing OK on a connection error at startup now retries instead of getting stuck.
  • Fixed multiplayer matches that sometimes never started when several players joined.

Crash reports

  • The game now sends us error and crash reports automatically, so we can fix problems faster. A report only contains your player ID and the game's own log.
